# Shubham Soule — Portfolio

An original, responsive portfolio built with React, TypeScript, and Vite.

## Run locally

```powershell
npm install
npm run dev
```

Create a production build with `npm run build`.

## Featured projects

### Cancer Stage Prediction

A research prototype for histopathology images that predicts one of five mapped cancer stages and estimates low, medium, or high progression risk.

- Uses transfer learning with ResNet50 or EfficientNet and focal loss for class imbalance.
- Produces Grad-CAM heatmaps, confusion matrices, classification reports, and prediction visualizations.
- Stack: Python, PyTorch, FastAPI, React, Vite, and Tailwind CSS.
- Research and education only; not a substitute for professional medical diagnosis.

[View the repository](https://github.com/shubhamss1018-commits/Cancer-detection-using-deep-learning-)

### CompIntel

An India-focused salary explorer that compares compensation across companies using normalized role levels rather than job titles alone.

- Search by role, company, city, and level; view company summaries and level breakdowns.
- Compare equivalent levels across companies and inspect base, bonus, and stock compensation.
- Calculates total compensation on the server and supports anonymous salary submissions.
- Stack: Next.js, React, TypeScript, PostgreSQL, Prisma, and Zod.

[Live project](https://compintel-ruby.vercel.app) · [Repository](https://github.com/shubhamss1018-commits/compintel)
